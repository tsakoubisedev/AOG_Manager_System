# AOG Manager demo

Open `index.html` in a browser to explore the demo. No installation, sign-in,
or Firebase connection is needed.

The demo starts with sample member records and lets you search, filter by
serving team, add or edit members, remove members, and record service
attendance. All changes are temporary and stay in the current page; they do
not affect the live application or its database.

## Host on Netlify

The repository's `netlify.toml` sets the publish directory to `demo`, so
Netlify can deploy this as a static site without a build command. Connect the
repository to Netlify and deploy; the site's URL will open this demo directly.
